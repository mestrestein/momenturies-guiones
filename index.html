Reglas para todos los guiones

    Conexión con GitHub

    Para guardar los cambios hace falta un token de GitHub. Se crea una vez y se queda guardado en este navegador.

    1. Entra en github.com/settings/personal-access-tokens/new con la cuenta mestrestein.
    2. Nombre: «Panel guiones». Caducidad: la que quieras.
    3. Repository access: Only select repositories → momenturies-guiones.
    4. Permissions → Repository permissions → Contents: Read and write.
    5. Generar y pegar aquí abajo.
